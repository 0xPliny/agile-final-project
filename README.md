# E-commerce Product Catalog — Agile Final Project

[Public Kanban board](https://github.com/users/0xPliny/projects/1) · [Sprint](https://github.com/0xPliny/agile-final-project/milestone/1)

This repository contains the course planning exercise and a **mock sprint**, not a backend implementation.

Ten stakeholder requirements are captured as issues with user stories, Gherkin acceptance criteria, labels, assignees, and story point estimates. Requirements 7 and 8 are deferred in Icebox. Requirements 9 and 10 are technical debt.

Sprint dates: **September 20–October 4, 2026** (14 days). Sprint scope: requirements 1–4, estimated at **10 points**. Goal: demonstrate creation and retrieval, then begin update and deletion.

The simulation ends with requirements 1–2 Done, requirement 3 In Progress, and requirement 4 in Sprint Backlog. Simulated completion does not mean application code was implemented.

Evidence and the explicitly simulated burndown will be stored in the evidence directory.
